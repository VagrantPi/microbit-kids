# 注音讀音資料

來自 [ButTaiwan/bpmfvs](https://github.com/ButTaiwan/bpmfvs) tag `v1.500`（與 `fonts/BpmfHuninn-Regular.ttf` 同一版）。

- `poyin_db.txt`：破音詞庫（讀音選擇工具 `ime/` 用的），MIT 授權，見 `LICENSE-MIT-poyin_db.txt`
- `phonic_table_Z.txt`：全部讀音表，順序＝字型的異體字選擇器順序，Apache 2.0，見 `LICENSE-2.0-phonic_table.txt`

讀音依據教育部《國語一字多音審訂表》與《重編國語辭典》。
**兩個檔案必須跟字型同一版**，否則選擇器編號會對不上，讀音會整個跑掉。
