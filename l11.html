🎮 LED 小遊戲：燈光快停

🎯

這一課要做到

做一個真的小遊戲！一顆燈在螢幕上來回跑，你要抓準時機按下按鈕，讓它停在正中間——停對了就贏！

1. LED 也有「地址」📍

25 顆燈每一顆都有自己的位置，用兩個數字表示：x 是第幾欄（左右，0～4）、y 是第幾列（上下，0～4）。用「點亮 x y」就能點亮指定的那一顆：

LED點亮 x 2 y 2

「點亮 x 2 y 2」就是正中間那一顆：

x=2, y=2 → 正中央
🐱 跟 Scratch 比一比Scratch 用 x、y 決定角色在舞台的位置；micro:bit 用 x、y 決定點亮哪一顆燈。一樣是座標，你早就懂！

2. 讓一顆燈自己來回跑 🏃

用一個盒子 x 記住燈在第幾欄，再用 dir（方向：1＝往右、-1＝往左）。每過一下下就移動一步，碰到邊邊就轉頭：

基本當程式開始
變數設定 x 為 0
變數設定 dir 為 1
迴圈重複無限次
基本清除螢幕
LED點亮 x x y 2
基本暫停 200 毫秒
變數x 改變 dir
邏輯如果 x ≥ 4 那麼
變數設定 dir 為 -1
邏輯如果 x ≤ 0 那麼
變數設定 dir 為 1

燈會像乒乓球一樣左右彈來彈去 🏓。改「暫停」的數字就能調快慢！

3. 按下按鈕來抓時機 🎯

按 A 的時候，檢查燈是不是正好在中間（x = 2）：對了顯示笑臉＋歡呼，不對就哭臉：

輸入當按鈕 A 被按下
邏輯如果 x = 2 那麼
基本顯示圖示 😀
音樂播放音調 中央 G 持續 1 拍
邏輯否則
基本顯示圖示 😢

恭喜你，這是一個真的遊戲了——有東西在動、有輸有贏！🎉

🎯 試試看（讓遊戲更好玩）

  1. 加計分：贏了就 score 改變 1，用「顯示數字」秀出分數。
  2. 把遊戲變難：把「暫停」數字改小，燈跑更快更難抓。
  3. 大挑戰：中三格都算贏（x = 1、2 或 3），或用傾斜控制一個籃子去接掉下來的燈。

✅ 我學會了

點一下把學會的打勾：

  • 我知道每顆 LED 有 x（欄）和 y（列）座標
  • 我用變數＋迴圈讓一顆燈自己來回跑，碰邊就轉頭
  • 我用按鈕＋「如果／否則」做出有輸有贏的小遊戲
