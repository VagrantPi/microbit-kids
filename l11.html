🎮 LED 小遊戲：燈光快停

🎯

今天只做一件事 🎯

一顆燈來回跑，你要抓準時機按 A，讓它停在正中間。

25 顆燈，每一顆都有自己的位置，用兩個數字說：

x＝左右第幾個（0～4）　　y＝上下第幾排（0～4）
1先點亮正中間那一顆
去 LED 抽屜（深紫色的），找 點亮 x 0 y 0

拖進「當啟動時」，兩個數字都改成 2。

基本當啟動時
LED點亮 x 2 y 2
👀 看一下正中央那一顆燈亮起來。
x=2, y=2 → 正中央
2做兩個盒子

去 變數 抽屜，建立兩個盒子：

📦 x＝燈現在在左右第幾個

📦 dir＝往哪邊跑（1 往右、-1 往左）

👀 看一下抽屜裡多出 x 和 dir 的積木。
3開機時先設定好

在 「當啟動時」 裡放兩塊「設為」：x 設為 0、dir 設為 1。

基本當啟動時
變數變數 x 設為 0
變數變數 dir 設為 1
👀 看一下畫面沒變化，是正常的 👍
4讓燈畫出來、再擦掉

在 「重複無限次」 裡放兩塊：先 「清空畫面」，再 「點亮 x y」。

x 的框框塞圓圓的 x，y 打 2。

迴圈重複無限次
基本清空畫面
LED點亮 x x y 2
👀 看一下最左邊中間那顆燈亮著，還不會動。
5讓它動起來

下面再加兩塊：「暫停 200 毫秒」，然後 「變數 x 改變」，框框裡塞圓圓的 dir。

迴圈重複無限次
基本清空畫面
LED點亮 x x y 2
基本暫停 200 毫秒
變數變數 x 改變 dir
👀 看一下燈往右邊跑⋯⋯然後跑出畫面不見了 😅 下一步修好它 👇
6跑到最右邊就轉頭

加一塊 「如果…那麼」——這次用沒有「否則」的那塊。

條件 x > 3，裡面放 「變數 dir 設為 -1」。

迴圈重複無限次
變數變數 x 改變 dir
邏輯如果 x > 3 那麼
變數變數 dir 設為 -1
👀 看一下燈跑到右邊會轉頭往回跑，但跑到左邊又不見了。
7跑到最左邊也轉頭

再加一塊一樣的，條件改成 x < 1，裡面放 「變數 dir 設為 1」。

迴圈重複無限次
基本清空畫面
LED點亮 x x y 2
基本暫停 200 毫秒
變數變數 x 改變 dir
邏輯如果 x > 3 那麼
變數變數 dir 設為 -1
邏輯如果 x < 1 那麼
變數變數 dir 設為 1
👀 看一下燈像乒乓球一樣左右彈來彈去 🏓
👩‍🏫 給大人
這是這套教材最難的一步。dir 存的是「方向」，碰到邊就把方向反過來——這個想法比積木本身難。
可以用手在桌上來回走給他看，走到桌邊就轉身，邊走邊說「現在 dir 是往右／現在改成往左」。
8拉一頂 A 的帽子，加上判斷

做一頂 A 的帽子，裡面放 有「否則」 的那塊。

條件是 x = 2（正中間）。

輸入當按鈕 A 被按下
邏輯如果 x = 2 那麼
（等一下放）
否則
（等一下放）
👀 看一下架子好了，兩條路還空著。
9贏了笑臉，輸了哭臉

那麼 放笑臉 ＋ 一個音（音效抽屜那塊長長的英文積木）。

否則 放哭臉。

🎮 換你玩

  1. 把「暫停 200」改小，燈跑更快、更難抓。
  2. 加分數：贏了就 score 改變 1，再用「顯示數字」秀出來。
