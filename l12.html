🍌 觸摸香蕉鋼琴

🎹

今天只做一件事 🎯

用香蕉當琴鍵！手一碰就發出聲音 🍌🎵

看 micro:bit 最下面那一排金色的大孔，上面寫著 0、1、2、3V、GND。

其中 P0、P1、P2 很特別——它們知道有沒有被碰到。

1拉一頂「碰到 P0」的帽子
去 輸入 抽屜（紫紅色的），找 當引腳 P0 被按下 （在輸入抽屜裡）
⚠️ 積木上寫「被按下」不是「被觸碰」，別找錯了。

拖到空白的地方。

輸入當引腳 P0 被按下
👀 看一下多了一頂帽子，上面寫著 P0。
2第一個琴鍵：放一個音

裡面放音效抽屜那塊長長的英文積木，拍數改 1/2 拍。

再放一塊「顯示數字」，打 1。

輸入當引腳 P0 被按下
音效play tone 中音 C for 1/2 拍 until done
基本顯示數字 1
👀 看一下在假的那台上，點一下 P0 那個金色的孔 → 響一聲 🎵
3第二個琴鍵：P1

再拖一頂一樣的帽子，點 P0 的選單改成 P1。

裡面的音改成 中音 E，數字打 3。

輸入當引腳 P1 被按下
音效play tone 中音 E for 1/2 拍 until done
基本顯示數字 3
👀 看一下點 P1 那個孔 → 不一樣的音 🎵
4第三個琴鍵：P2

做法一樣，選單改 P2，音改 中音 G，數字打 5。

輸入當引腳 P2 被按下
音效play tone 中音 G for 1/2 拍 until done
基本顯示數字 5
👀 看一下三個孔各一個音——三個琴鍵完成 🎹
碰一下就唱歌
5夾上香蕉

用鱷魚夾，一端夾 P0，另一端夾一根香蕉 🍌

👀 看一下線接好了，但還不會響。下一步是關鍵 👇
6手要捏住 GND

再用一條線夾住 GND。

你的手捏住它不要放，另一隻手去碰香蕉。

💡 沒有香蕉也行鋁箔紙、金屬湯匙、濕海綿、朋友的手⋯⋯只要會導電都行。
👀 看一下碰香蕉 → 發出聲音 🍌🎵
👩‍🏫 給大人
最常見的失敗原因就是手放掉了 GND。
電要繞一圈才會通：板子 → 香蕉 → 手 → GND → 回到板子。手鬆開，圈就斷了。
另外香蕉太乾也可能不靈，換一根或改用濕海綿。

🎮 換你玩

  1. 三個音換成你喜歡的，彈一小段旋律。
  2. 用不同水果當琴鍵，看哪一種最好彈。
