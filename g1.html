⭐ 接星星

⭐

今天只做一件事 🎯

星星從上面掉下來，你在最下面一排左右跑，把它接住。

畫面最下面那一排是你。

上面掉下來的是星星。

接到 → 加分 ＋「叮」；漏接 → 少一條命 ＋「嗚」。

🎮基本關做完這 10 步，遊戲就可以玩了。

👀 看一下抽屜裡多出寫著 px 的積木。

6別讓自己跑出去

在 「重複無限次」 的最上面加兩塊 「如果…那麼」（沒有「否則」的那塊）。

去 邏輯 抽屜（藍綠色的），找 < （第二塊要點選單改成 >）
🔎 在「比較（Comparison）」那一區
迴圈重複無限次

👀 看一下走到邊邊就停住，不會再不見了 ✋
👩‍🏫 給大人
< 和 > 是同一塊積木，點積木上的符號用選單換。孩子常以為要找兩塊不同的。
7做星星的兩個盒子

再建立兩個盒子：sx（星星在左右第幾個）、sy（星星掉到第幾排）。

在 「當啟動時」 裡設定：sy 設為 0，sx 設為 隨機取數 0 到 4。

基本當啟動時
變數變數 px 設為 2
變數變數 sy 設為 0
變數變數 sx 設為
數學隨機取數 0 到 4
👀 看一下還是只看得到你自己。下一步星星才會出現 👇
8把星星畫出來，讓它掉下來

在「重複無限次」裡，你的下面再加三塊：

迴圈重複無限次
LED點亮 x px y 4
LED點亮 x sx y sy
基本暫停 400 毫秒
變數變數 sy 改變 1
👀 看一下星星從最上面一格一格往下掉 ⭐ 掉出去就不見了。
9接到了嗎？

在「sy 改變 1」的下面加一塊 「如果…那麼」，條件是 sy > 4（星星掉出去了，該算帳）。

裡面再放一塊有「否則」的，條件是 sx = px。

邏輯如果 sy > 4 那麼
邏輯如果 sx = px 那麼
接到了 → 等一下放
否則
漏接了 → 等一下放
👀 看一下架子搭好了，還沒放東西進去。
10接到加分，漏接扣命

先再建立兩個盒子：score（分數）和 life（命）。

在「當啟動時」裡 score 設為 0、life 設為 3。

然後把兩條路填滿：

邏輯如果 sy > 4 那麼
邏輯如果 sx = px 那麼
變數變數 score 改變 1
音效play tone 高音 C for 1/4 拍 until done
否則
變數變數 life 改變 -1
音效play tone 低音 C for 1/4 拍 until done
變數變數 sy 設為 0
變數變數 sx 設為
數學隨機取數 0 到 4
⚠️ 最後兩塊要放在外面「sy 設為 0」和「sx 設為 隨機」要放在「如果 sy > 4」的裡面、但在「否則」的外面——不管接到沒接到，都要放一顆新星星。
👀 看一下可以玩了！ 接到「叮」⭐ 漏接「嗚」😵
👩‍🏫 給大人
到這裡就是一個完整的遊戲了，可以先停在這裡讓他玩個過癮。
後面的加料關是「還想加什麼」才做，做幾關都可以。
🍬加料關一關一個小點子，做幾關都可以，隨時停下來都算完成。

14加料 ④：開場來個掃描動畫

在 GO 的下面加一塊 「計次 index 從 0 到 4 執行」（迴圈抽屜）。

裡面放 「點亮 x index y 2」 和 「暫停 100 毫秒」。

迴圈計次 index 從 0 到 4 執行
LED點亮 x index y 2
基本暫停 100 毫秒
👀 看一下開機時中間那排燈一顆一顆亮過去 ➡️
👩‍🏫 給大人
「計次」就是「從 0 數到 4，每數一次做一遍」。它跟第 5 課的「重複 N 次」差別是：計次知道自己數到幾，那個數字就放在 index 裡，可以直接拿來用。

這一關多用到：計次 index 從 0 到 4 執行

15加料 ⑤：畫一張自己的開場圖

16加料 ⑥：星星在哪邊？給個提示

覺得太難的話，讓它先用箭頭告訴你星星在左邊還右邊。

在「重複無限次」裡加 「如果 sx < px 那麼」 → 顯示箭頭 選西（左）；否則 → 選東（右）。

邏輯如果 sx < px 那麼

否則

箭頭數字 東

👀 看一下箭頭一直指著星星的方向 🧭（會蓋住畫面，玩過癮就可以拿掉）

這一關多用到：顯示箭頭

17加料 ⑦：越玩越快

把 「暫停 400 毫秒」 裡的 400 換成一個算式：

去 數學 抽屜拿 減法 和 乘法，拼成 400 - score × 20。

基本暫停
數學400 -
數學score × 20
毫秒
👀 看一下分數越高，星星掉得越快 🔥
👩‍🏫 給大人
分數很高時這個算式會變成負數，micro:bit 會當成 0（全速）。對玩起來沒問題，但如果他問「為什麼不會更快了」，這就是答案。

這一關多用到：減法、乘法

在「重複無限次」裡加 「如果 光線感測值 < 50 那麼」 → 暫停 300 毫秒。
