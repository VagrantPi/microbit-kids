🔢 按按計數器

🔢

今天只做一件事 🎯

按一下加一，幫你數東西。

這個遊戲會用到一個盒子（變數）——就是那個記數字的小盒子。

只用一個，慢慢來就會了 👍

🎮基本關做完這 5 步就能玩了。
1先做一個盒子
去 變數 抽屜（深紅色的），按 「建立一個變數…」

名字打 n（一個英文字母就好，好打又好認）。

👀 看一下變數抽屜裡多出了 n 的積木。
👩‍🏫 給大人
名字用英文 n 是刻意的——打中文要切注音，會卡住他。
2開機先歸零

在 「當啟動時」 裡放 「變數 n 設為 0」。

let n = 0
👀 看一下畫面沒變化——這一步是在做準備，正常 👍
3按 A 就加一
去 輸入 抽屜（紫紅色的），找 當按鈕 A 被按下

拖到空白處，裡面放 「變數 n 改變 1」。

input.onButtonPressed(Button.A, function () {
    n += 1
})
👀 看一下按 A 還沒反應，因為還沒叫它秀出來。
4把數字秀出來
去 基本 抽屜（藍色的），找 顯示數字

放在「變數 n 改變 1」的下面，白框框塞圓圓的 n。

input.onButtonPressed(Button.A, function () {
    n += 1
    basic.showNumber(n)
})
👀 看一下可以玩了！ 按 A → 1、2、3⋯⋯它記住了 🔢
5玩玩看

拿它去數點東西：數樓梯、數跳繩、數家裡有幾雙鞋。

👀 看一下數字一直往上加，不會自己忘記
👩‍🏫 給大人
這就是變數最好懂的用法：它記得上一次的數字。
他如果問「為什麼不是一直 1」，就是抓到重點了——「改變 1」是在原本的數字上加，不是設成 1。
🍬加料關一關一個小點子，做幾關都可以。
6加料 ①：按 B 重來

再拉一頂 B 的帽子，裡面放 「變數 n 設為 0」和顯示數字 n。

input.onButtonPressed(Button.B, function () {
    n = 0
    basic.showNumber(n)
})
👀 看一下按 B → 變回 0，可以重新數 🔄

這一關多用到：變數 n 設為

7加料 ②：數到 10 放煙火
去 邏輯 抽屜（藍綠色的），找 如果 … 那麼 （這次要沒有「否則」的那塊）

放在「顯示數字」的下面，條件是 n = 10，裡面放一個笑臉。

if (n == 10) {
    basic.showIcon(IconNames.Happy)
}
👀 看一下數到 10 的時候會跳出笑臉 🎉

這一關多用到：如果…那麼、=

8加料 ③：搖一搖也能重來
去 輸入 抽屜（紫紅色的），找 當姿勢 晃動 發生

一頂「晃動」帽子，裡面跟按 B 做一樣的事。

input.onGesture(Gesture.Shake, function () {
    n = 0
    basic.showNumber(n)
})
👀 看一下搖一搖 → 歸零，兩種重來方式都可以 🤾

這一關多用到：當姿勢 晃動 發生

🎮 換你玩

  1. 用它數你家有幾雙鞋。
  2. 把「數到 10」改成你想要的數字。
