🔨 打地鼠

🔨

今天只做一件事 🎯

地鼠隨機冒出來。在左邊就按 A，在右邊就按 B。

這個遊戲跟接星星寫法不一樣。

接星星是「一直畫、一直動」；打地鼠是「等你按，時間到就算了」。

🎮基本關做完這 8 步，遊戲就可以玩了。
1做地鼠的盒子

建立兩個盒子：mx（地鼠在左右第幾個）、score（分數）。

在 「當啟動時」 裡把 score 設為 0。

👀 看一下抽屜裡多出 mx 和 score。
2讓地鼠隨機冒出來

在 「重複無限次」 裡放：清空畫面，再把 mx 設為 隨機取數 0 到 4。

迴圈重複無限次
基本清空畫面
變數變數 mx 設為
數學隨機取數 0 到 4
👀 看一下畫面還是黑的——盒子換了數字，但還沒畫出來。
3把地鼠點亮
去 LED 抽屜（深紫色的），找 點亮 x 0 y 0

x 塞圓圓的 mx，y 打 2（中間那排）。

LED點亮 x mx y 2
👀 看一下中間那排一直有一顆燈在亂跳 🐹
4讓它停久一點

下面加一塊 「暫停 800 毫秒」，給你時間反應。

基本暫停 800 毫秒
👀 看一下地鼠停一下才換位置，看得清楚了 👀
5問問看你有沒有在按 A
去 輸入 抽屜（紫紅色的），找 按鈕 A 被按下？ （圓圓的那塊，在輸入抽屜）
🤔 這塊跟帽子不一樣「當按鈕 A 被按下」是帽子，你一按它就跳出來做事。
「按鈕 A 被按下？」是問句，它只回答「現在有沒有在按」。

先拖到空白處放著，下一步要用。

輸入按鈕 A 被按下？
👀 看一下認得這塊就打勾 ✅
👩‍🏫 給大人
這是這個遊戲的重點：事件（等你按）和詢問（現在按著嗎）是兩種不同的做法。
打地鼠要在「地鼠出現的那段時間內」檢查，所以用問句比較順。
6地鼠在左邊還是右邊？

在「暫停」上面加一塊有「否則」的判斷，條件是 mx < 2（左半邊）。

邏輯如果 mx < 2 那麼
地鼠在左邊 → 要按 A
否則
地鼠在右邊 → 要按 B
👀 看一下架子搭好了，還沒放東西。
7按對了就加分

那麼（左邊）裡面放 「如果 按鈕 A 被按下？ 那麼」 → score 改變 1 ＋ 一個高音。

否則（右邊）一樣，但改成 按鈕 B 被按下？。

邏輯如果 mx < 2 那麼

那麼
變數變數 score 改變 1
音效play tone 高音 C for 1/4 拍 until done

輸入按鈕 B 被按下？
那麼
變數變數 score 改變 1

👆 要按著不放地鼠出現的那一瞬間要正在按著，它才數得到。
所以玩的時候手指壓著比較好中。
👀 看一下可以玩了！ 按對 → 「叮」🔨
8看分數

在「重複無限次」最下面加一塊 「顯示數字 score」，再加 「暫停 300 毫秒」。

基本顯示數字 score
基本暫停 300 毫秒
👀 看一下每打完一隻，畫面會閃一下分數 🔢
👩‍🏫 給大人
到這裡遊戲就完整了。後面的加料關可做可不做。
🍬加料關一關一個小點子，做幾關都可以。
9加料 ①：地鼠會閃，比較好認
去 LED 抽屜（深紫色的），找 點的狀態切換 x 0 y 0

用它做「亮 → 暗 → 亮」，地鼠就會閃。

在「點亮」下面放：暫停 200、點的狀態切換 x mx y 2、暫停 200、再一塊點的狀態切換。

LED點亮 x mx y 2
基本暫停 200 毫秒
LED點的狀態切換 x mx y 2
基本暫停 200 毫秒
LED點的狀態切換 x mx y 2
👀 看一下地鼠會一閃一閃 ✨

這一關多用到：點的狀態切換 x y

10加料 ②：打完就把它熄掉
去 LED 抽屜（深紫色的），找 不點亮 x 0 y 0

在「按對了加分」的裡面，加一塊 「不點亮 x mx y 2」。

LED不點亮 x mx y 2
👀 看一下打中的那一瞬間地鼠就消失了，手感好很多 🔨

這一關多用到：不點亮 x y

11加料 ③：沒按到就「嗚」一聲

給「如果 按鈕 A 被按下？」加上 否則，裡面放一個低音。

再放一塊 「rest for 1/4 拍」（音效抽屜），讓聲音之間有空隙。

邏輯如果
輸入按鈕 A 被按下？
那麼
變數變數 score 改變 1
否則
音效play tone 低音 C for 1/4 拍 until done
音效rest for 1/4 拍
👀 看一下沒打到會「嗚」一聲，知道自己漏掉了 😵

這一關多用到：rest for

12加料 ④：兩顆都沒按才算漏

用 「或」（邏輯抽屜）把兩個問句串起來：

「如果 (按鈕 A 被按下？ 或 按鈕 B 被按下？) 那麼」 → 表示「你有在按其中一顆」。

邏輯如果
輸入按鈕 A 被按下？
或
輸入按鈕 B 被按下？
那麼
你有按（不管哪一顆）
🔀 「或」是什麼兩邊只要有一邊成立，整句就成立。
👀 看一下看得懂就打勾 ✅

這一關多用到：或

13加料 ⑤：換一種迴圈寫法
去 迴圈 抽屜（綠色的），找 重複 判斷 false 執行

把 false 換成 true（邏輯抽屜那塊）。

😲 這樣就跟「重複無限次」一樣了「重複 判斷 true 執行」＝ 只要條件成立就一直做，而 true 永遠成立，所以它永遠不會停。
迴圈重複 判斷 true 執行
跟「重複無限次」做一樣的事
👀 看一下看得懂就打勾 ✅（不用真的換掉，知道有這種寫法就好）
👩‍🏫 給大人
之後要做「命還沒用完就一直玩」這種條件迴圈，用的就是這塊。「躲石頭」那個遊戲會真的派上用場。

這一關多用到：重複 判斷 執行、true

14加料 ⑥：碰金色的孔加分
去 輸入 抽屜（紫紅色的），找 當引腳 P0 被按下 （輸入抽屜）

拉出來，裡面放 「變數 score 改變 5」。

手捏著 GND，另一手碰 P0 → 偷偷加 5 分 😈

16加料 ⑧：把燈調暗一點
去 LED 抽屜（深紫色的），再點它下面的 更多，找 燈光 亮度設為 255
🔎 這塊不在 LED 抽屜的第一層，要先點更多才看得到
📂 什麼是「更多」有些抽屜點開之後，最下面還有一個叫 「更多」的。
比較少用的積木都收在那裡，點一下就展開了。

放進 「當啟動時」，數字改成 80。

LED燈光 亮度設為 80
👀 看一下整片燈變柔和了，晚上玩不刺眼 🌙

這一關多用到：燈光 亮度設為

🎮 換你玩
