🔢

今天只做一󠇡件事 🎯

每按一󠇡下 A 就加 1，數字顯示在螢幕上。

要記住「按了幾下」，需要一󠇡個󠇡小盒子󠇡 📦。

盒子󠇡裡裝一󠇡個󠇡數字。

可以看裡面是多少，也可以換掉它。

👩‍🏫 給大人
程式裡這種盒子󠇡叫「變數」。孩子󠇡這一󠇡課只要抓住「盒子󠇡裝一󠇡個󠇡數字」的畫面就夠了，「變數」這個󠇡詞不󠇡用背，之後自然會接上。
1打開變數抽屜
去 變數 抽屜（深紅色的）
🔍 它在很下面抽屜由上往下數：基本、輸入、音效、LED、廣播、迴圈、邏輯、變數、數學。
上面的音效也是紅色的，別點錯——變數在倒數󠇡第二個。

最上面有一󠇢顆按鈕：「建立一󠇡個󠇡變數…」。

👀 看一󠇡下看到那顆按鈕了嗎？看到就打勾 ✅
2做一󠇡個󠇡盒子󠇡，名字󠇡叫 count

按下 「建立一󠇡個󠇡變數…」。

打上 count，按確定。

👀 看一󠇡下抽屜裡多出三塊新積木，上面都有 count。
👩‍🏫 給大人
count 是英文「數數」。用英文是因為󠇡 MakeCode 的變數名不吃中文，打不出來時可以改用 n 之類的短名字󠇡，不影響學習。
3開機先把盒子󠇡歸零
去 變數 抽屜（深紅色的），找 變數 count 設為 0

拖進 「當啟動時」 裡面。

數字不󠇡用改，就留 0。

let count = 0
📦 「設為 0」是什麼把盒子󠇡裡的東西整個換成 0。
👀 看一󠇡下畫面沒有變化。這一󠇡步是在做準備，是正常的 👍
4拉一󠇢頂 A 的帽子󠇡

去 輸入 抽屜，拿 「當按鈕 A 被按下」（第 3 課學過）。

放在空󠇡白的地方。

input.onButtonPressed(Button.A, function () {

})
👀 看一󠇡下畫面上多了一󠇢頂空空的帽子󠇡。
5帽子󠇡裡放「加一󠇡個󠇡」
去 變數 抽屜（深紅色的），找 變數 count 改變 1

拖進帽子󠇡裡。

input.onButtonPressed(Button.A, function () {
    count += 1
})
👀 看一󠇡下點 A 還是沒反應󠇡。因為󠇡還沒叫它秀出來，下一󠇡步 👇
6放一󠇡塊「顯示數字」
去 基本 抽屜（藍色的），找 顯示數字

放在「改變 1」的下面。

    count += 1
    basic.showNumber(0)
})
👀 看一󠇡下點 A → 一󠇢直出現 0。快好了，再一󠇡步 👇
7把圓圓的 count 拖進白框框

回 變數 抽屜，最下面有一󠇡塊圓圓的 count。

把它拖進「顯示數字」的白色框框裡。

input.onButtonPressed(Button.A, function () {
    count += 1
    basic.showNumber(count)
})
👀 看一󠇡下點 A → 1，再點 → 2，再點 → 3⋯⋯它記住了！
👩‍🏫 給大人
圓形積木要「塞進」白框框，這個󠇡拖放動作對小手是難的。如果對不準，可以先把「顯示數字」拉到空󠇡白處󠇡放大空間，塞好再拖回帽子󠇡裡。
8再拉一󠇢頂 B 的帽子󠇡

做法跟第 4 步一󠇡樣，但把 A 改成 B。

input.onButtonPressed(Button.B, function () {

})
👀 看一󠇡下畫面上有兩頂帽子󠇡了。
9B 的帽子󠇡裡放「設為 0」

再拖一󠇡塊 「變數 count 設為 0」 進去。

input.onButtonPressed(Button.B, function () {
    count = 0
})
👀 看一󠇡下點 A 幾下讓數字變大，再點 B——螢幕沒反應󠇡。再一󠇡步就好 👇
10最後放一󠇡塊「顯示數字 count」

跟第 6、7 步一󠇡樣：放「顯示數字」，再把圓圓的 count 塞進去。

    count = 0
    basic.showNumber(count)
})
✨ 這一󠇡課最重要的一󠇡件事「改變 1」＝ 在原本的數字上再加 1（3 變 4）。
「設為 0」＝ 整個換成 0。
👀 看一󠇡下數字亂跳之後，點 B → 回到 0 🎉
👩‍🏫 給大人
「改變」vs「設為」是這課唯一的觀念，其他都是操作。
驗收方式：問他「如果我想一󠇡次加 5，要改哪裡？」答得󠇡出來改「改變」後面那個󠇡數字，就是懂了。

🧠 不󠇡看步驟，自己再做一󠇡次

input.onButtonPressed(Button.B, function () {
    count = 0
    basic.showNumber(count)

最後螢幕上是多少？先用想的，不󠇡要按 🤔

先選一󠇡個󠇡：
答對了 ⭐　拿板子󠇡照順序按一󠇡次，看看是不󠇡是真的這樣 👀
你算的好像是：按 A 就變成 1。
可是「改變 1」是在原本的數字上再加 1 喔。
你好像忘了 B。
按 B 會把盒子󠇡裡的數字整個換成 0。
按 B 不󠇡是加 1 喔。
「設為 0」是把盒子󠇡裡的數字整個換成 0。
一󠇡個󠇡一󠇡個󠇡按，每按一󠇡下就想：「盒子󠇡裡現在是多少？」
拿起板子󠇡，照上面的順序按一󠇡次，看看螢幕是多少 👀

👩‍🏫 給大人
自己重󠇡做是在看他是不󠇡是真的記得󠇡，不󠇡是照著步驟搬；看提示要打 answer，有打開過會記下來。
通關數字每次都不一󠇡樣，答案不󠇡在頁面上。打錯的數字會對到常見的錯誤想法，只給那一󠇡句提示、不公布答案，再換一󠇢題。錯兩次會停下來請他舉手：你看過之後，在框框裡打 teacher 就能繼續。
右下角的小圓點：🟢 順利、🟡 錯過或看過提示、🔴 在等你過去、🟣 說有把握卻答錯（就是「說懂但不󠇡會」）。
