第 4 課🎉 這一課完成！

🔢 神奇計數器

🔢

今天只做一件事 🎯

每按一下 A 就加 1，數字顯示在螢幕上。

要記住「按了幾下」，需要一個小盒子 📦。

盒子裡裝一個數字。

可以看裡面是多少，也可以換掉它。

👩‍🏫 給大人
程式裡這種盒子叫「變數」。孩子這一課只要抓住「盒子裝一個數字」的畫面就夠了，「變數」這個詞不用背，之後自然會接上。
1打開變數抽屜
去 變數 抽屜（深紅色的）
🔍 它在很下面抽屜由上往下數：基本、輸入、音效、LED、廣播、迴圈、邏輯、變數、數學。
上面的音效也是紅色的，別點錯——變數在倒數第二個。

最上面有一顆按鈕：「建立一個變數…」。

👀 看一下看到那顆按鈕了嗎？看到就打勾 ✅
2做一個盒子，名字叫 count

按下 「建立一個變數…」。

打上 count，按確定。

👀 看一下抽屜裡多出三塊新積木，上面都有 count。
👩‍🏫 給大人
count 是英文「數數」。用英文是因為 MakeCode 的變數名不吃中文，打不出來時可以改用 n 之類的短名字，不影響學習。
3開機先把盒子歸零
去 變數 抽屜（深紅色的），找 變數 count 設為 0

拖進 「當啟動時」 裡面。

數字不用改，就留 0。

基本當啟動時
變數變數 count 設為 0
📦 「設為 0」是什麼把盒子裡的東西整個換成 0。
👀 看一下畫面沒有變化。這一步是在做準備，是正常的 👍
4拉一頂 A 的帽子

去 輸入 抽屜，拿 「當按鈕 A 被按下」（第 3 課學過）。

放在空白的地方。

輸入當按鈕 A 被按下
👀 看一下畫面上多了一頂空空的帽子。
5帽子裡放「加一個」
去 變數 抽屜（深紅色的），找 變數 count 改變 1

拖進帽子裡。

輸入當按鈕 A 被按下
變數變數 count 改變 1
👀 看一下點 A 還是沒反應。因為還沒叫它秀出來，下一步 👇
6放一塊「顯示數字」
去 基本 抽屜（藍色的），找 顯示數字

放在「改變 1」的下面。

輸入當按鈕 A 被按下
變數變數 count 改變 1
基本顯示數字 0
👀 看一下點 A → 一直出現 0。快好了，再一步 👇
7把圓圓的 count 拖進白框框

回 變數 抽屜，最下面有一塊圓圓的 count。

把它拖進「顯示數字」的白色框框裡。

輸入當按鈕 A 被按下
變數變數 count 改變 1
基本顯示數字 count
👀 看一下點 A → 1，再點 → 2，再點 → 3⋯⋯它記住了！
點了 3 下
👩‍🏫 給大人
圓形積木要「塞進」白框框，這個拖放動作對小手是難的。如果對不準，可以先把「顯示數字」拉到空白處放大空間，塞好再拖回帽子裡。
8再拉一頂 B 的帽子

做法跟第 4 步一樣，但把 A 改成 B。

輸入當按鈕 B 被按下
👀 看一下畫面上有兩頂帽子了。
9B 的帽子裡放「設為 0」

再拖一塊 「變數 count 設為 0」 進去。

輸入當按鈕 B 被按下
變數變數 count 設為 0
👀 看一下點 A 幾下讓數字變大，再點 B——螢幕沒反應。再一步就好 👇
10最後放一塊「顯示數字 count」

跟第 6、7 步一樣：放「顯示數字」，再把圓圓的 count 塞進去。

輸入當按鈕 B 被按下
變數變數 count 設為 0
基本顯示數字 count
✨ 這一課最重要的一件事「改變 1」＝ 在原本的數字上再加 1（3 變 4）。
「設為 0」＝ 整個換成 0。
👀 看一下數字亂跳之後，點 B → 回到 0 🎉
👩‍🏫 給大人
「改變」vs「設為」是這課唯一的觀念，其他都是操作。
驗收方式：問他「如果我想一次加 5，要改哪裡？」答得出來改「改變」後面那個數字，就是懂了。

🎮 換你玩

  1. 把「改變 1」改成「改變 2」，看每按一下跳多少。
  2. 做一個比分板：A 加 1 分，B 改成「改變 -1」變成減 1 分。

✅ 我學會了

都做到了就點一下，蓋完成章 🎉
