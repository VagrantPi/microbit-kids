🧭 歪歪指路

🧭

今天只做一件事 🎯

板子歪哪邊，箭頭就指哪邊。

這個遊戲只用兩種積木，四步就能玩。

不用盒子（變數）、不用數格子、也沒有聲音 🤫

🎮基本關做完這 4 步就能玩了。
1拉一頂「姿勢」帽子
去 輸入 抽屜（紫紅色的），找 當姿勢 晃動 發生

拖到空白的地方，點 晃動 的選單，改成 「左側偏低」。

input.onGesture(Gesture.TiltLeft, function () {

})
👀 看一下帽子上寫著「左側偏低」。
👩‍🏫 給大人
「左側偏低」就是往左邊歪。選單裡還有右側偏低、正面朝上、背面朝上。
2往左歪就指左邊
去 基本 抽屜（藍色的），找 顯示箭頭 （基本抽屜的最後一塊）

拖進帽子裡，選單選 西——西就是左邊。

input.onGesture(Gesture.TiltLeft, function () {
    basic.showArrow(ArrowNames.West)
})
👀 看一下把板子往左歪 → 箭頭指左 ⬅️
3再做一頂：往右歪

做法一模一樣：再拉一頂帽子改成 「右側偏低」，裡面的箭頭選 東（東就是右邊）。

input.onGesture(Gesture.TiltRight, function () {
    basic.showArrow(ArrowNames.East)
})
👀 看一下往右歪 → 箭頭指右 ➡️
4玩玩看

兩頂帽子都做好了，左右歪一歪試試。

👀 看一下可以玩了！ 歪左指左、歪右指右 🧭
👩‍🏫 給大人
玩法建議：你喊「左！」「右！」，他要在一秒內歪對邊。
喊快一點就變成反應遊戲，兩個人輪流當喊的人。
🍬加料關一關一個小點子，做幾關都可以。
5加料 ①：放平就收起來

再拉一頂帽子改成 「正面朝上」，裡面放 清空畫面。

input.onGesture(Gesture.ScreenUp, function () {
    basic.clearScreen()
})
👀 看一下板子放平 → 箭頭不見了 ✨

這一關多用到：清空畫面

6加料 ②：翻過來就生氣

一頂 「背面朝上」 的帽子，裡面放 顯示圖示，挑一個生氣的臉。

basic.showIcon(IconNames.Angry)
👀 看一下把板子翻過來 → 它生氣了 😠

這一關多用到：顯示圖示

7加料 ③：搖一搖變尋寶羅盤

一頂 「晃動」 的帽子，裡面放 如果…那麼…否則，條件用抽籤（改成 0 到 1）= 0。

那麼放箭頭 西、否則放箭頭 東。

input.onGesture(Gesture.Shake, function () {
    if (randint(0, 1) == 0) {
        basic.showArrow(ArrowNames.West)
    } else {
        basic.showArrow(ArrowNames.East)
    }
})
👀 看一下搖一搖 → 它隨便指一邊，假裝寶藏在那裡 🗺️

這一關多用到：隨機取數、如果…否則

🎮 換你玩

  1. 跟家人玩「喊左喊右」，看誰歪錯邊。
  2. 把箭頭換成你自己畫的圖案。
