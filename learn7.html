今天只做一󠇡件事 🎯

這一󠇢章認識 5 塊積木，一󠇡次一󠇡塊。

1點亮 x y
led.plot(0, 0)

指定一󠇢顆燈亮起來。x 是左右第幾個󠇡、y 是上下第幾排（都從 0 數）。

去 LED 抽屜（深紫色的），找 點亮 x 0 y 0

換你做：拖進「當啟動時」，x 和 y 都打 2。

🙈 偷看答案
led.plot(2, 2)
👀 看一󠇡下正中央亮起一󠇢顆燈 💡
2不點亮 x y
led.unplot(0, 0)

指定一󠇢顆燈熄掉。跟「點亮」剛好相󠇡反。

去 LED 抽屜（深紫色的），找 不點亮 x 0 y 0

換你做：放在「點亮 x 2 y 2」的下面，中間夾一󠇡塊「暫停 500」。

🙈 偷看答案
led.plot(2, 2)
basic.pause(500)
led.unplot(2, 2)
👀 看一󠇡下燈亮一󠇡下就被關掉了
3點的狀態切換
led.toggle(0, 0)

那顆燈亮的變暗、暗的變亮。一󠇡塊就能做閃爍。

去 LED 抽屜（深紫色的），找 點的狀態切換 x 0 y 0

換你做：放進「重󠇡複無限次」，後面加一󠇡塊「暫停 500」。

🙈 偷看答案
basic.forever(function () {
    led.toggle(2, 2)
    basic.pause(500)
})
👀 看一󠇡下正中央那顆一󠇢閃一󠇢閃 ✨
4點的狀態（問句）
led.point(0, 0)

圓圓的問句：那顆燈現在亮不󠇡亮？回答「是」或「不󠇡是」。

❓ 圓圓的問句，答案是「是／不󠇡是」它不󠇡會在燈上畫東西，要配「如果」才看得󠇡出效果。
去 LED 抽屜（深紫色的），找 點的狀態 x 0 y 0

換你做：把它拖進「如果」的六角形洞裡。

🙈 偷看答案
if (led.point(2, 2)) {
    basic.showIcon(IconNames.Yes)
}
👀 看一󠇡下六角形的洞被塞滿了，但還看不出效果
5燈光 亮度設為
led.setBrightness(255)

整片燈調亮或調暗。0 最暗、255 最亮。

🔅 中間的亮度，這頁的假螢幕畫不出來它只有亮和暗兩種，演不出「比較暗」——這個󠇡要看真的板子󠇡才明顯，我們不假裝。
去 LED 抽屜（深紫色的），再點它下面的 更多，找 燈光 亮度設為 255
🔎 這塊不󠇡在 LED 抽屜的第一層，要先點更多才看得󠇡到

換你做：放在「顯示圖示」的前面，數字改成 64。

🙈 偷看答案
led.setBrightness(64)
basic.showIcon(IconNames.Heart)
👀 看一󠇡下圖案變得󠇡比較暗（要看真的板子󠇡才明顯）
