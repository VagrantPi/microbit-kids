🪨 躲石頭󠇡

🪨

今天只做一󠇡件事 🎯

石頭󠇡一󠇢直掉下來，左右閃開。活越久，分越高。

這個󠇡遊戲用一󠇢招新的：不󠇡用比座標，直接問 micro:bit——

「我站的那一󠇢格，燈是不󠇡是亮著？」亮著就代表撞到了 💥

🎮基本關做完這 9 步，遊戲就可以玩了。
1做四個盒子󠇡

建立：px（你在哪）、rx（石頭󠇡在哪）、ry（石頭󠇡掉到第幾排）、score（分數）。

在 「當啟動時」 裡：px 設 2、ry 設 0、score 設 0，rx 設 隨機取數 0 到 4。

👀 看一󠇡下畫面沒變化，是正常的 👍
2用「重󠇡複 判斷」當󠇡主迴圈
去 迴圈 抽屜（綠色的），找 重󠇡複 判斷 false 執行

把 false 換成一󠇡個󠇡判斷：score < 999。

🤔 為󠇡什麼不󠇡用「重󠇡複無限次」因為󠇡等一󠇡下撞到石頭󠇡時要讓它停下來。
只要把 score 設成 999，這個󠇡迴圈就會自己結束。

放在 「當啟動時」 裡、剛才那些「設為」的下面。

while (score < 999) {

}
👀 看一󠇡下架子󠇡搭好了，裡面還空空的。
👩‍🏫 給大人
這是「用一󠇡個󠇡變數當󠇡開關」的入門。
比起「重󠇡複無限次 ＋ 一󠇡個󠇡 playing 旗標」，直接把條件寫在迴圈上，孩子󠇡比較看得󠇡出「什麼時候會停」。
3把石頭󠇡畫出來、讓它掉

迴圈裡放：清空畫面 → 點亮 x rx y ry → 暫停 400 毫秒 → ry 改變 1。

while (score < 999) {
    basic.clearScreen()
    led.plot(rx, ry)
    basic.pause(400)
    ry += 1
}
👀 看一󠇡下一󠇢顆石頭󠇡從上面掉下來 🪨 掉出去就不󠇡見了。
4石頭󠇡掉完就換一󠇢顆新的

加一󠇡塊 「如果 ry > 4 那麼」：

裡面 ry 設 0、rx 設 隨機取數 0 到 4、score 改變 1。

if (ry > 4) {
    ry = 0
    rx = randint(0, 4)
    score += 1
}
👀 看一󠇡下石頭󠇡一󠇢顆接一󠇢顆不停掉下來 🪨🪨🪨
5把你自己畫出來

在「點亮石頭󠇡」的下面加 「點亮 x px y 4」。

led.plot(px, 4)
👀 看一󠇡下最下面多了一󠇢顆燈，那是你 🔆
6A 往左、B 往右

跟接星星一󠇡樣，做兩頂帽子󠇡改 px。

input.onButtonPressed(Button.A, function () {
    px += -1
})
input.onButtonPressed(Button.B, function () {
    px += 1
})
👀 看一󠇡下你可以左右移動了 ⬅️➡️
7新招：問它「我這格亮著嗎」
去 LED 抽屜（深紫色的），找 點的狀態 x 0 y 0 （圓圓的問句）
💥 這就是撞到判定石頭󠇡先畫、你後畫。
如果畫你之前那一󠇢格已經亮著，就表示石頭󠇡在你身上——撞到了。

先拖到空󠇡白處󠇡，下一󠇡步要用。

led.point(px, 4)
👀 看一󠇡下認得󠇡這塊就打勾 ✅
8撞到就停下來

把它放在 「點亮 x px y 4」的上面，配一󠇡塊 「如果…那麼」：

if (led.point(px, 4)) {
    basic.showIcon(IconNames.Sad)
    score = 999
}
⚠️ 順序很重要一󠇡定要放在「點亮 x px y 4」的上面。
先問「亮著嗎」，才輪到你把自己畫上去，不然永遠都是亮的。
👀 看一󠇡下撞到石頭󠇡 → 哭臉 😢 遊戲停住了。
👩‍🏫 給大人
這一󠇡步最容易錯位。孩子󠇡把判斷放到「點亮自己」下面的話，遊戲會一󠇢開始就結束——因為󠇡他自己把那格點亮了。
看到一󠇢開機就哭臉，就是這個󠇡原因。
9撞到之前活了幾秒？

在「如果撞到」裡，哭臉的上面先放一󠇡塊 「顯示數字 score」。

💡 用 999 當󠇡結束訊號的副作用score 被設成 999 之後就不󠇡是分數了。
所以要先秀出來，再設 999。
if (led.point(px, 4)) {
    basic.showNumber(score)
    basic.showIcon(IconNames.Sad)
    score = 999
}
👀 看一󠇡下可以玩了！ 撞到 → 先看到分數，再看到哭臉 😢
🍬加料關一󠇢關一󠇡個󠇡小點子󠇡，做幾關都可以。
10加料 ①：撞到的時候長長「嗚——」一󠇢聲
去 音效 抽屜（紅色的），找 演奏 音階 中音 C （短的那塊，中文的）
🔎 在「音高（Tone）」那一󠇢區
🔊 這次故意用它第 8 課說過這塊聲音不󠇡會停。
這裡剛好利用這一󠇢點——撞到就一󠇢直叫，直到你叫它停。

音改成 低音 C，放在哭臉前面。

music.ringTone(131)
👀 看一󠇡下撞到 → 一󠇢直「嗚——」不停 😱 下一󠇢關來關掉它。

這一󠇢關多用到：演奏 音階

11加料 ②：兩秒後讓它閉嘴
去 音效 抽屜（紅色的），找 停止播放所有音效
🔎 要往下捲，在「音量（Volume）」那一󠇢區

在「演奏 音階」後面放 「暫停 2000 毫秒」，再放這一󠇡塊。

music.ringTone(131)
basic.pause(2000)
music.stopAllSounds()
👀 看一󠇡下「嗚——」響兩秒就安靜了 🤫

這一󠇢關多用到：停止播放所有音效

12加料 ③：兩顆石頭󠇡一󠇢起掉

再做兩個󠇡盒子󠇡 rx2、ry2，照第 3、4 步再來一󠇡次。

撞到判定不󠇡用改——點的狀態本來就不管是哪一󠇢顆石頭󠇡 😎

led.plot(rx, ry)
led.plot(rx2, ry2)
👀 看一󠇡下兩顆石頭󠇡一󠇢起掉，難度直接翻倍 🪨🪨
👩‍🏫 給大人
這一󠇢關是在讓他體會「用燈的狀態判定碰撞」的好處󠇡：石頭󠇡再多，判斷都只有一󠇡塊積木。
如果是比座標的寫法，每多一󠇢顆石頭󠇡就要多一󠇢組條件。
13加料 ④：越熱掉越快
去 輸入 抽屜（紫紅色的），找 溫度感測值 (°C)
🔎 要往下捲，大概在第 9 塊

把 「暫停 400」 的數字換成 400 - 溫度感測值 × 5。

basic.pause(400 - input.temperature() * 5)
👀 看一󠇡下手握住板子󠇡暖一󠇡下 → 石頭󠇡掉得󠇡更快 🔥
👩‍🏫 給大人
室溫大概 25 度，所以暫停約 275 毫秒。手握住會升到 30 度以上，掉得󠇡明顯更快。這是把感測器接上遊戲難度的第一步。

這一󠇢關多用到：溫度感測值

14加料 ⑤：兩台連線，比誰活得󠇡久（先講暗號）
去 廣播 抽屜（粉紅色的），找 廣播群組設為 1
🔎 在「Group」那一󠇢區（最上面）

放進 「當啟動時」，數字保持 1。

radio.setGroup(1)
👀 看一󠇡下畫面上出現兩台假的 micro:bit 了！

這一󠇢關多用到：廣播群組設為

15加料 ⑥：死掉就把分數喊出去
去 廣播 抽屜（粉紅色的），找 廣播發送數字 0
🔎 在「Send」那一󠇢區

放在「如果撞到」裡面，數字框塞圓圓的 score。

⏰ 要放在設成 999 之前不然傳出去的會是 999。
radio.sendNumber(score)
👀 看一󠇡下其中一󠇢台撞到 → 另一󠇢台收到了（下一󠇢關才看得󠇡到）📡

這一󠇢關多用到：廣播發送數字

16加料 ⑦：收到對手的分數就比一󠇢比
去 廣播 抽屜（粉紅色的），找 當收到廣播數字 receivedNumber （一󠇢頂帽子󠇡）
🔎 在「Receive」那一󠇢區

裡面放 「如果 score > receivedNumber 那麼」 → 顯示文字 WIN，否則 → 顯示文字 LOSE。

radio.onReceivedNumber(function (receivedNumber) {
    if (score > receivedNumber) {
        basic.showString("WIN")
    } else {
        basic.showString("LOSE")
    }
})
👀 看一󠇡下兩台比分數，贏的那台跑出 WIN 🏆

這一󠇢關多用到：當收到廣播數字

17加料 ⑧：用文字喊話
去 廣播 抽屜（粉紅色的），找 廣播發送文字
🔎 在「Send」那一󠇢區

撞到的時候，除了送分數，再送一󠇡句 DEAD。

radio.sendString("DEAD")
👀 看一󠇡下送出去了，但還沒人在聽。下一󠇢關 👇

這一󠇢關多用到：廣播發送文字

18加料 ⑨：聽到對手掛了就慶祝
去 廣播 抽屜（粉紅色的），找 當收到廣播文字 receivedString （一󠇢頂帽子󠇡）
🔎 在「Receive」那一󠇢區

裡面放 「重󠇡複 3 次 執行」，裡面放笑臉、暫停 200、清空畫面、暫停 200。

radio.onReceivedString(function (receivedString) {
    for (let index = 0; index < 3; index++) {
        basic.showIcon(IconNames.Happy)
        basic.pause(200)
        basic.clearScreen()
        basic.pause(200)
    }
})
👀 看一󠇡下對手一󠇡撞到，你這台就笑臉閃三下 😀🎉

這一󠇢關多用到：當收到廣播文字、重󠇡複 N 次 執行

19加料 ⑩：石頭󠇡剛好砸在你頭上才算

用 「且」（邏輯抽屜）寫另一󠇢種撞到判定：

「如果 (ry = 4 且 rx = px) 那麼」 → 撞到。

if (ry == 4 && rx == px) {
    basic.showIcon(IconNames.Sad)
}
🔗 「且」是什麼兩邊都要成立，整句才成立。
👀 看一󠇡下看得󠇡懂就打勾 ✅
👩‍🏫 給大人
這是跟第 7 步「點的狀態」完全不同的解法，結果一󠇡樣。
值得󠇡問他：「兩顆石頭󠇡的時候，哪一󠇢種寫起來比較短？」答案是「點的狀態」——這就是選對工具的價值。

這一󠇢關多用到：且
