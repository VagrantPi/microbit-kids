💡 小夜燈

💡

今天只做一件事 🎯

天一黑它自己亮，變亮又自己熄掉。

這次板子會自己感覺四周亮不亮 👀

不用盒子（變數）、不用數格子、也沒有聲音。

🔌 這個要用手蓋住板子做完記得下載到真的板子，用手蓋住才試得出來。
🎮基本關做完這 5 步就能玩了。
1先拿一個「一直做」的架子
去 基本 抽屜（藍色的），找 重複無限次

它跟「當啟動時」一樣，一開始就在畫面上。

basic.forever(function () {

})
👀 看一下畫面上有一個 C 形的大架子。
👩‍🏫 給大人
要用「重複無限次」是因為它得一直盯著亮度。放進「當啟動時」只會看一次就結束。
2放一個岔路口進去
去 邏輯 抽屜（藍綠色的），找 如果 … 那麼 … 否則 （要有「否則」的那塊）

拖進「重複無限次」裡面。

basic.forever(function () {
    if (true) {

    } else {

    }
})
👀 看一下架子裡多了一個岔路口，兩格都還空空的。
3問它「現在很暗嗎？」
去 邏輯 抽屜（藍綠色的），找 < （念做「小於」）
🔎 在「比較（Comparison）」那一區

把 < 拖進六角形的洞裡。

去 輸入 抽屜（紫紅色的），找 光線感測值 （0 是全黑，255 是很亮）
🔎 要往下捲，大概在第 7 塊

左邊塞光線感測值，右邊打 50。

input.lightLevel() < 50
👀 看一下條件看起來像「光線感測值 ＜ 50」。
👩‍🏫 給大人
50 只是個起點。教室很亮的話可以調大一點（例如 100），讓他自己試哪個數字最好用——這比背數字有用。
4暗的時候亮起來
去 基本 抽屜（藍色的），找 顯示圖示

拖進 那麼 裡面，挑一個你喜歡的圖。

basic.showIcon(IconNames.Heart)
👀 看一下用手蓋住板子 → 圖案亮起來 ❤️
5亮的時候熄掉
去 基本 抽屜（藍色的），找 清空畫面

拖進 否則 裡面。

basic.forever(function () {
    if (input.lightLevel() < 50) {
        basic.showIcon(IconNames.Heart)
    } else {
        basic.clearScreen()
    }
})
👀 看一下可以玩了！ 手蓋住就亮、手拿開就暗 💡
🍬加料關一關一個小點子，做幾關都可以。
6加料 ①：現在到底多亮？
去 基本 抽屜（藍色的），找 顯示數字
🔧 這一關要先把「如果」拉開把整塊 如果…否則 拖到旁邊空白處放著（先不要刪掉），「重複無限次」裡只放一塊「顯示數字」，白框框塞光線感測值。
量完再把「如果」放回去。
basic.forever(function () {
    basic.showNumber(input.lightLevel())
})
👀 看一下數字一直跑——手慢慢蓋上去，數字會變小 🔢
👩‍🏫 給大人
為什麼要先把「如果」拉開：不拉開的話，蓋住時走的是「那麼」那條路、只會看到圖案，根本看不到數字，門檻就量不出來。
讓他記下「蓋住」和「沒蓋住」大概各是多少，中間那個數就是該填進「＜」的值。

這一關多用到：顯示數字、光線感測值

7加料 ②：換成自己畫的圖
去 基本 抽屜（藍色的），找 顯示指示燈

把「顯示圖示」換成這塊，自己點一張小夜燈的圖。

basic.showLeds(`
    . # . # .
    # # # # #
    # # # # #
    . # # # .
    . . # . .
    `)
👀 看一下天黑時亮出你畫的圖案 🎨

這一關多用到：顯示指示燈

8加料 ③：晚上不要太刺眼
去 LED 抽屜（深紫色的），再點它下面的 更多，找 燈光 亮度設為 255
🔎 這塊不在 LED 抽屜的第一層，要先點更多才看得到

放進 「當啟動時」 裡面，數字改成 64。

led.setBrightness(64)
🎩 為什麼不能放在「重複無限次」上面「重複無限次」是帽子——上面沒有缺口，接不了東西。
只要設定一次就好的事，都放進「當啟動時」。
👀 看一下亮起來柔和多了，適合放床頭 🌙

這一關多用到：燈光 亮度設為

🎮 換你玩

  1. 把它放進鞋盒裡，開關燈看看反應。
  2. 找出你家最適合的那個數字，把 50 換掉。
