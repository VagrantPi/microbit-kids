第 7 課🎉 這一課完成！

🦸 micro:bit 的超能力

🦸

今天只做一件事 🎯

做一支溫度計，再做一個會自己亮的小夜燈。

你有皮膚，感覺得到冷熱。

你有眼睛，感覺得到亮暗。

micro:bit 身上也有會感覺的小零件 👂

🌡️ 知道幾度　　💡 知道亮不亮　　🤸 知道有沒有歪一邊

它會把感覺到的東西，變成一個數字給你用。

1拉一頂 A 的帽子，放「顯示數字」

帽子跟「顯示數字」都學過了，先把它們拼好。

輸入當按鈕 A 被按下
基本顯示數字 0
👀 看一下點 A → 出現 0。
2換成「它感覺到的溫度」
去 輸入 抽屜（紫紅色的），找 溫度感測值 (°C) （圓圓的那種積木，在輸入抽屜）

拖進「顯示數字」的白色框框裡。

輸入當按鈕 A 被按下
基本顯示數字
輸入溫度感測值 (°C)
👀 看一下點 A → 跳出現在幾度 🌡️
🔥 試試看下載到真的板子，手指壓住板子暖一下再按 A——數字會變大！
👩‍🏫 給大人
積木上寫「溫度感測值」，講給孩子聽就說「它感覺到的溫度」。圓形積木＝一個數字，可以塞進任何白框框，這個概念第 4 課已經鋪過。
3小夜燈：找到「重複無限次」

小夜燈要一直盯著房間亮不亮。

畫面上那塊綠色的 「重複無限次」 就是拿來做這個的。

迴圈重複無限次
👀 看一下找到那塊綠色的就打勾 ✅
4裡面放「如果…那麼…否則」
去 邏輯 抽屜（藍綠色的），找 如果 … 那麼 … 否則 （要有「否則」的那塊）

拖進「重複無限次」裡面。

迴圈重複無限次
邏輯如果 （等一下放） 那麼
（等一下放）
否則
（等一下放）
👀 看一下架子搭好了，裡面還空空的。
5填條件：比 50 還暗
去 邏輯 抽屜（藍綠色的），找 < （念做「小於」，在邏輯抽屜）
去 輸入 抽屜（紫紅色的），找 光線感測值 （0 是全黑，255 是很亮）

把它們拼成 「光線感測值 < 50」，放到「如果」後面。

邏輯如果
輸入光線感測值
< 50 那麼
（等一下放）
否則
（等一下放）
🔍 「<」念做「小於」整句是「現在比 50 還暗」。
👀 看一下條件填好了，兩條路還是空的。
6暗就亮星星，亮就關掉

那麼 裡面放「顯示圖示」，選星星。

否則 裡面放 「清空畫面」。

迴圈重複無限次
邏輯如果
輸入光線感測值
< 50 那麼
基本顯示圖示 ⭐
否則
基本清空畫面
👀 看一下用手蓋住板子 → 星星亮 ✨；放開 → 熄掉。
變暗 → 夜燈亮
👩‍🏫 給大人
如果太晚亮或一直亮著，把 50 調大或調小。室內光線差異很大，這個數字本來就要現場試——讓孩子自己試出「他家的數字」，比給他標準答案好。
7拉一頂「往左歪」的帽子
去 輸入 抽屜（紫紅色的），找 當姿勢 晃動 發生

拖出來，點 晃動 的選單，改成 「左側偏低」。

輸入當姿勢 左側偏低 發生
👀 看一下多了一頂帽子，上面寫著「左側偏低」。
👩‍🏫 給大人
「左側偏低」就是往左邊歪。選單裡還有右側偏低、正面朝上、背面朝上、標誌朝上、自由掉落——都可以讓他玩玩看。
8裡面放向左的箭頭

放一塊「顯示圖示」，選向左的箭頭。

輸入當姿勢 左側偏低 發生
基本顯示圖示 ⬅️
👀 看一下把板子往左歪 → 箭頭指左 ⬅️
往左歪
9再做一頂「往右歪」的

做法一模一樣，選單改成 「右側偏低」，圖案選向右的箭頭。

輸入當姿勢 右側偏低 發生
基本顯示圖示 ➡️
👀 看一下往左歪 → 指左；往右歪 → 指右。像方向盤 🚗
往右歪

🎮 換你玩

  1. 把夜燈的 50 改成 100 或 20，找出最好用的數字。
  2. 做一個怕熱的臉：溫度大於 30 就哭臉 😢，不然就笑臉 😀。
