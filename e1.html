✌️ 猜拳機

✌️

今天只做一件事 🎯

搖一搖，micro:bit 幫你出石頭、剪刀或布。

這個遊戲不用盒子（變數），也不用數格子。

三張圖你自己畫，搖一搖就隨機出一張 🎲

🎮基本關做完這 7 步，遊戲就可以玩了。
1拉一頂「搖一搖」的帽子
去 輸入 抽屜（紫紅色的），找 當姿勢 晃動 發生

拖到空白的地方，什麼都不用改。

輸入當姿勢 晃動 發生
👀 看一下畫面多了一頂紫紅色的帽子。
2先畫一個石頭
去 基本 抽屜（藍色的），找 顯示指示燈 （在基本抽屜，藍色的）

拖進帽子裡，照下面這樣點格子：

石頭 ✊
輸入當姿勢 晃動 發生
基本顯示指示燈 ✊ 石頭
👀 看一下搖一搖（假的那台按 SHAKE）→ 出現石頭 ✊
3拿出抽籤積木
去 數學 抽屜（紫色的），找 隨機取數 0 到 10
🔎 要往下捲，大概在第 12 塊

先拖到空白的地方放著。

把 10 改成 2——這樣它會抽出 0、1、2 三個數字之一。

數學隨機取數 0 到 2
👀 看一下積木上寫著「隨機取數 0 到 2」。
4問它「抽到 0 嗎？」
去 邏輯 抽屜（藍綠色的），找 如果 … 那麼 … 否則 （要有「否則」的那塊）

拖進帽子裡。條件用 邏輯 抽屜的 =，左邊塞抽籤積木、右邊打 0。

再把石頭那塊搬進 那麼 裡面。

邏輯如果
數學隨機取數 0 到 2
= 0 那麼
基本顯示指示燈 ✊ 石頭
否則
（等一下放）
👀 看一下搖一搖：有時候出石頭，有時候什麼都沒有。快好了 👇
5在「否則」裡再問一次

再拖一塊「如果…那麼…否則」，放進 否則 裡面。

條件是另一塊抽籤積木（這次改成 0 到 1）= 0。

邏輯如果
數學隨機取數 0 到 1
= 0 那麼
（等一下放剪刀）
否則
（等一下放布）
👀 看一下架子搭好了，兩格還空空的。
👩‍🏫 給大人
為什麼要再抽一次、而且範圍是 0 到 1：
第一次抽 0～2，抽中 0 的機率是 1/3 → 石頭。
剩下的 2/3 再抽 0～1，各一半 → 剪刀 1/3、布 1/3。
三種剛好各 1/3，很公平。
如果改成「否則如果 抽籤 0～2 = 1」再抽一次，機率就會跑掉——因為那是重新抽，不是接續前面的結果。
6畫剪刀

拖一塊「顯示指示燈」放進那麼，照這樣點：

剪刀 ✌️
基本顯示指示燈 ✌️ 剪刀
👀 看一下搖一搖：石頭跟剪刀輪流出現了。最後一張 👇
7畫布

再拖一塊放進否則，這次整片點滿：

布 🖐️
輸入當姿勢 晃動 發生
邏輯如果
數學隨機取數 0 到 2
= 0 那麼
基本顯示指示燈 ✊ 石頭
否則
邏輯如果
數學隨機取數 0 到 1
= 0 那麼
基本顯示指示燈 ✌️ 剪刀
否則
基本顯示指示燈 🖐️ 布
👀 看一下可以玩了！ 搖一搖 → 石頭、剪刀、布隨機出一個 ✌️
👩‍🏫 給大人
到這裡就是一個完整的遊戲了，可以先讓他跟你猜個十盤。
他很可能會發現「怎麼一直出布」——那正好，讓他數一數十次裡各出幾次，這是機率的第一課。
🍬加料關一關一個小點子，做幾關都可以。
8加料 ①：出拳前先「預備」

在「如果」的上面加兩塊：顯示圖示（挑一個你喜歡的）和 暫停 500 毫秒。

基本顯示圖示 👀
基本暫停 500 毫秒
👀 看一下搖一搖 → 先閃一下，才出拳，比較有儀式感 🥁

這一關多用到：顯示圖示、暫停

9加料 ②：出拳的時候「叮」一聲

去 音效 抽屜，拿那塊長長的英文積木（第 8 課那塊）。

放在「顯示圖示」的下面，什麼都不用改。

音效play tone 中音 C for 1 拍 until done
👀 看一下出拳前會「叮」一聲 🔔
👩‍🏫 給大人
這裡刻意不改音名——用預設的就好。想換音的話，第 8 課教過：點選單用耳朵挑。

這一關多用到：play tone

10加料 ③：過幾秒自己擦掉

在帽子的最下面加 暫停 3000 毫秒 和 清空畫面。

基本暫停 3000 毫秒
基本清空畫面
👀 看一下出拳三秒後畫面自己清乾淨，準備下一局 🔄

這一關多用到：清空畫面

11加料 ④：想知道玩了幾次嗎？
📦 這一關會用到變數變數就是第 4 課那個記數字的小盒子。
覺得難就直接跳過——前面十步已經是一個完整的遊戲了 👍

建立一個盒子叫 n，在 「當啟動時」 裡設為 0。

帽子最上面加 「變數 n 改變 1」，最下面加 「顯示數字 n」。

基本當啟動時
變數變數 n 設為 0
變數變數 n 改變 1
基本顯示數字 n
👀 看一下每搖一次，數字就多 1 🔢

這一關多用到：變數、顯示數字

🎮 換你玩

  1. 把石頭、剪刀、布換成你自己畫的圖。
  2. 跟家人玩十盤，數數看各出了幾次。
